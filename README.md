# 跨境电商 AI 智能客服与工单管理系统

> **基于 RAG 架构与安全边界管控的智能客服平台（独立全栈开发）**

本项目是我从 0 到 1 独立设计并开发的跨境电商 AI 智能客服系统。项目基于 Python Flask 和 RAG（检索增强生成）技术构建，旨在解决高客单价电商场景下人工客服回复慢、知识更新滞后的痛点。系统完整覆盖了售前咨询、售后理赔以及人工工单协同的全业务流程。

在技术实现上，我重点攻克了大模型在商业应用中的“幻觉”难题。通过自研的**双层边界规则引擎**（关键词+语义理解）与**置信度熔断机制**，有效拦截了退款、赔偿等高敏意图，确保 AI 不会违规承诺。同时，系统支持业务规则的动态热加载，运营人员无需重启服务即可实时调整策略，大幅提升了系统的运维效率与合规性。

### 核心技术栈
Python · Flask · RAG (BGE-M3/LangChain) · LLM 应用开发 · 前端三件套

### 快速开始
1. 克隆仓库并安装依赖：`pip install -r requirements.txt`
2. 配置 `.env` 环境变量（LLM API Key 等）。
3. 运行 `python app.py` 启动本地服务即可体验。
